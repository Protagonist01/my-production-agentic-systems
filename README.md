# my-production-agentic-systems

Production-minded AI agents across five industries, built around one shared evaluation and resilience harness.

## Delivery scope

- Shared platform: model gateway, strict replay, fresh evaluation, fault injection, observability and release evidence.
- E-commerce: Olist support and controlled refunds on source-grounded order records.
- Fintech: CFPB complaint classification, calibrated routing and review.
- Revenue operations: contract extraction, deterministic reconciliation and controlled corrections.
- Healthcare: cited policy-criterion assessment and review recommendations.
- Logistics: disruption assessment and budget-constrained actions in a documented simulation.

## Current status

Repository initialized on 2026-10-11. Project management, source-data plans and implementation contracts are being established. No agent runtime, validated source imports or evaluation results are claimed yet.

The first release is the real shared platform integrated with an Olist workflow: authentic order context, enforced action rules, durable state, review handling, traces and reproducible evaluation. Test doubles and mock business backends support verification; they do not replace the application implementation.
