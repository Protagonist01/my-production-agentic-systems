## Concrete execution direction

1. Preserve the new mismatches as development evidence. Do not tune or rename this captured
   comparator, promote the twelve exposed cases to holdout, or declare the native labels
   independently validated because they are published.
2. Establish semantic reference applicability before freezing another quality cohort.
   Native coarse intent, requested amount role, reship and clarification need distinct
   support. Existing constructed methods stay development-only. Source permission and
   annotation-task fit must be exact; a general source URL supplies neither by itself.
3. If a model judge is proposed, qualify it against independently supported correct and
   incorrect answers for its exact field/slices. Test false acceptance/rejection, abstention,
   group dependence and missing outputs. Judge/candidate agreement cannot be its own truth.
4. Freeze the selected candidate, comparator, complete grouped cohort/slice design, external
   reference/evaluator pins, protocol, uncertainty/abstention/cost/latency limits and actual
   execution host before a new provider request. The74attempt preparation estimate is not
   that freeze or an approved allocation. The expired/stopped study is not resumed.
5. Require the final candidate's actual service outcomes and operational/recovery evidence,
   independently reread, before qualification and separate release acceptance.

Current reference evidence therefore permits useful development comparisons, but does not
yet support an honest full-language qualification claim. Software test success and customer
confirmation authority cannot substitute for the missing interpretation evidence.
