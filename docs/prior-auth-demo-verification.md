## Local database and real-browser check

compilation and an invented note missing education. The first scripted assessment
published six criterion invocations, with education insufficient and no provider
calls. The protected browser desk showed those findings and the synthetic-demo limits.

only education through the visible document form and advanced the case to revision2.
The existing authenticated operator import accepted the fixed supplement at revision3.
The same bounded worker reassessed only education. Readback found all seven states
met with mapped sources. This agreement is with the authored demonstration, not
clinical truth. A subsequent worker invocation claimed no job and sent no requests.

## Independent reference-payer evidence

The local browser instance did **not** connect to a payer. The hosted workflow built
the pinned independent HL7 reference process and exercised the authenticated SQL/API
desk against it. It checked both the complete document-wait path and two packets for
the same invented patient. Stable item trace numbers produced one correlated inquiry
response per packet. Repeated submission returned the stored receipt rather than
another POST. The observed review code wasA3, not a clinical approval.

Separate fault tests cover unknown submissions, index-only crashes, concurrent
duplicates, changed revisions/bindings, viewer/tenant denial and case locking during
dispatch. The browser session regressions also cover late payer responses after
logout. These mechanism tests do not measure payer business acceptance or clinical
accuracy. See the [payer guide](prior-auth-payer-desk.md).
