## Sources and use boundaries

The selected policy is [CMS NCD 240.4, version 3](https://www.cms.gov/medicare-coverage-database/view/ncd.aspx?ncdid=226&ncdver=3),
effective March 13, 2008, covering the national initial CPAP evidence requirements. It is
distinct from contractor-specific LCD L33718. The application extracts the national covered
indications before the separate Coverage with Evidence Development provisions. Continued
coverage, CED enrollment and local documentation/billing rules are outside this slice.

CMS pages may contain third-party licensed coding material; government hosting does not
establish blanket redistribution rights. The compiler uses selected code-free policy prose,
with source byte pins and exact normalized-text citation offsets. It does not copy a CPT,
CDT or SNOMED catalog. [CMS coding terminology and licensing notices](https://www.cms.gov/medicare-coverage-database/search.aspx)
distinguish ICD diagnosis codes from CPT/HCPCS procedure and equipment codes. Syntax alone
does not prove a code exists, is effective on a service date, matches a diagnosis or supports
coverage. This implementation does not validate code catalogs or accept code-only coverage
claims. Such requests require qualified review and later versioned coding data.

Illustrative source records come from the publisher's [Synthea sample archive](https://synthetichealth.github.io/downloads.html).
The publisher describes the generated data as usable without restriction for secondary use.
These are published synthetic records, not real patients or original clinician transcription.
MTSamples was investigated but direct access returned 403 and use rights were unresolved;
it is not the chosen source and access controls were not bypassed. NHS/credentialed MIMIC
alternatives were investigated but are not silently substituted into this cohort.

## Execution and evaluation

Use `python -m prior_auth.prepare --help` to verify independently pinned source files and
prepare private policy/narrative artifacts. Source and evaluator paths must be outside Git.
The command refuses an existing output directory. Supply the manifest-file digest separately
from its contents. Source custody verifies size and SHA256 on the same bytes subsequently parsed.

Use the workspace environment, or install the base Prior Auth wheel alongside
`production-agent-harness[gemini]` for live use. The base source/preparation modules do not
load a provider client. Configure `GEMINI_API_KEY` and `GEMINI_FREE_TIER_CONFIRMED=true` in
ignored `.env.local`. Do not place a key in command arguments, reports or Git.

```powershell
python -m prior_auth.cli --root . --policy D:/private/policy.json --policy-sha256 POLICY_SHA --cases D:/private/cohort.json --cases-sha256 COHORT_SHA --split development --output D:/private/dev-run-v1 --deadline-seconds 600
```

The CLI injects the existing shared budgeted Gemini gateway. Each criterion has at most one
attempt; the run admits at most seven requests per case, at most twelve selected cases and an
explicit elapsed deadline. No paid route or fallback exists. Provider failures remain failures;
missing model output cannot receive a correct-case score. Per-case data, full exchanges and
the aggregate report are private files. JSON reports retain model-completion and denominator
counts separately from conservative fallback dispositions.

Model calls use `gemini-3.5-flash-lite`, zero temperature, LOW thinking and 512 output tokens
per criterion. [Google's model card](https://ai.google.dev/gemini-api/docs/models/gemini-3.5-flash-lite)
and [free-tier data-use conditions](https://ai.google.dev/gemini-api/docs/pricing) were inspected
on October 23, 2026. Use invented or permitted illustrative content; no real patient data was
sent. The billing-disabled project is user-confirmed, not independently attested by the SDK.

Retrieval uses visible note text and fixed criterion terms. The candidate receives the full
redacted note, relevant source criterion and retrieved span candidates, not expected labels.
The server resolves exact, exactly matching model quotes into offsets; nonexistent or over-repeated quotes fail closed; all bounded repeated occurrences are retained. The output checker verifies citation integrity, policy/date bindings and a deliberately narrow,
transparent support grammar. Unsupported paraphrases remain insufficient. Contradictory
visible negatives and multiple reported rates require review. This conservative recognizer
is not a general medical entailment model.

The only final dispositions are evidence complete for review, request information and
qualified review. No approval is executed. P3 evidence-completeness errors must not be
renamed clinical incorrect-authorization rates. P6 release metrics, clinical review and a
production authorization system remain distinct future work.
